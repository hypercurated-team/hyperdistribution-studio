## Description

How big is this creator, really? HyperJudge turns every reel into a quick guessing game.

Tap once on any reel. Pick how many followers you think the creator has, from 1K to 10M+. Keep watching. A moment later the real number and your score drop in as a banner, and you never leave the video.

Score big with a sharp eye. Land on the same step and you get 3 points. One step off gets 1. Build a streak and climb the daily leaderboard against your friends.

Set up in three taps. Add the HyperJudge shortcut, put it on AssistiveTouch or Back Tap, and start playing.

- One tap from any reel
- 13 simple steps, from 1K to 10M+
- 3 points for a bullseye, 1 for close
- Streaks and a fresh leaderboard every day
- Optional Hypercurated account, the same as HyperMixer

HyperJudge is part of the HyperMixer family. It is not affiliated with, endorsed by or sponsored by Instagram or Meta.

## App privacy (App Store Connect)

Tracking: **No**. Data collected, all **linked to the user**, used only for **App Functionality**, not used for tracking:

- Contact info: Email address, Name
- Identifiers: User ID
- User content: Gameplay content (leaderboard name, points, streak)

Not collected: photos, location, contacts, browsing history, usage data, diagnostics. The shortcut sends the text on screen to work out the creator; it is not stored.

## Review notes (App Store)

HyperJudge is a guessing game played on top of short videos. A round runs through the HyperJudge shortcut (bundled in the app) so the player never leaves the video:

1. Open HyperJudge > Setup > "Add the shortcut" and add it in Shortcuts.
2. Set AssistiveTouch Single-Tap (or Back Tap) to HyperJudge.
3. On any public reel, tap the button, pick a guess, and the result arrives as a notification banner.

Signing in is optional and only needed for the leaderboard. Account deletion: tap your name > Delete account. A screen recording of a full round is attached.
